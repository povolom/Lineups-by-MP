# Lineups by MP

A personal research desk for daily fantasy: bookmark players with their salaries, see who is worth their price tonight, build lineups under the cap and keep a ledger of what I entered and won.

**Status:** coming soon. **Page:** https://lineups.marcantoniopovolo.com

The full build plan is in [SPEC.md](SPEC.md). Hard rules: it never connects to Yahoo (salaries are typed or pasted by hand), projections are labelled as estimates, keys stay secret, and it costs nothing to run.

Built by [Marcantonio Povolo](https://marcantoniopovolo.com). I decide what it does and review and test each change; AI coding tools help write the code.
